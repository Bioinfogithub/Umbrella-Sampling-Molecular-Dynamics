# Input files

Place the system-specific input files here.

Typical inputs include:

- `system.pdb` or the equilibrated starting structure
- `topol.top` and required `.itp` files
- `index.ndx`
- the equilibrated structure used to start the pulling simulation

These files are intentionally not included in this repository because they are system-specific and may be large or subject to redistribution restrictions.

For a real project, document the source of the structure, force field, water model, GROMACS version, and any ligand/ion parameters used.
