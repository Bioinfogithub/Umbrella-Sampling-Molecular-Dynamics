# Umbrella Sampling and Molecular Dynamics

A computational molecular dynamics workflow for umbrella sampling, free-energy analysis, and potential of mean force (PMF) calculations using GROMACS.

## Workflow

System Preparation
→ Energy Minimization
→ Equilibration
→ Umbrella Sampling
→ Production MD
→ PMF Calculation
→ Free-Energy Analysis

## Methods

- Molecular Dynamics (MD)
- Umbrella Sampling
- Potential of Mean Force (PMF)
- Free-Energy Analysis
- GROMACS
